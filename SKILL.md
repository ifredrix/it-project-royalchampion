# IT-Project — Skill Directory & Role Specifications (Agentic AI Workflow-Based)

> Source: Integrated Tasks & AI Agent Workflow Enrichment
> Version: 1.0 Code Name: Royal Champion | Date: 2026-09-07

## A. Technical & Architectural Roles

### Software Architect

* System architecture design, bounded contexts, & technology mapping.
* Codebase analysis & business logic mapping using interactive knowledge graphs (*Understand-Anything*).
* Generation of structured HTML/SVG-based system architecture diagrams (*Architecture Diagram Generator*).
* System security design, cyber resilience analysis, & setting conditional architectural standards (*Cortex AI Skills*).

### Lead Developer (Tech Lead)

* Translating business requirements into technical specifications & breaking down features into measurable tasks.
* Implementation of *Contextual Commits* specifications to log architectural decision trails ("WHY") in git commits.
* Allocating team technical tasks & overseeing cross-agent code integration.
* Bridging communication between business and technical stakeholders & evaluating code quality standards.

### Front-End Developer

* User interface development & visual component integration.
* Applying precision component patterns based on *Awesome Agent Skills* references (such as Next.js best practices).
* Integrating UI logic with APIs & accessibility testing.

### Back-End Developer

* System logic programming, APIs, & database management.
* Handling serverless DB integration, egress optimization, & automation instrument integration.
* Securing data flows, encryption management, & logic injection prevention.

---

## B. Project Management & Multi-Agent Orchestration

### Project Manager (PM)

* Schedule, budget, & human/agent resource allocation management.
* Orchestrating multi-agent parallel tasks using directory isolation protocols (*Agent Smith*) to avoid execution conflicts.
* Monitoring delay risks & mitigating workflow overlaps.

### Scrum Master

* Facilitating Agile/Scrum methodologies & managing work cycles (Sprints).
* Conducting Daily Standups & identifying technical and operational bottlenecks for the team.
* Monitoring agent workflow compliance with isolated execution rules.

---

## C. Design, Strategy & Research

### UX Researcher

* Usability testing & design validation.
* Executing structured two-phase deep comparative research workflows (*Deep Research Skills*) for market & user studies.
* Formulating evidence-backed recommendations for improvement (*evidence-backed analysis*).

### UX/UI Designer

* Designing user journey maps, wireframes, & visual design.
* Aligning interfaces with visual design system standards & creating product visual asset guidelines.

---

## D. Testing, Security & Agent Governance

### QA Automation Engineer

* Writing automated test scripts across frameworks (Web, Mobile, API).
* Integrating automated test pipelines into CI/CD Pipelines.
* Testing resilience under negative scenarios & system load limits.

### Security Tester (Penetration Tester)

* Identifying security vulnerabilities, cyber penetration testing, & credential auditing.
* Testing agent workflow resilience against prompt injection threats & private data exposure.

### AI Skill & Governance Specialist (New Role)

* Mining work sessions to extract repetitive workflows into *agent skills* (*Skill Miner*).
* Auditing, personalizing, & analyzing team *skill trigger* compatibility (*Skill Personalizer & Optimizer*).
* Generalizing & sanitizing sensitive context prior to publishing *skills* (*Skill Generalizer*).

---

## E. Infrastructure, Release & Agent Enterprise Operations

### DevOps Engineer

* Setting up CI/CD Pipelines & automating application deployment.
* Integrating automated verification gates (*Review Gates*) into deployment workflows.
* Managing cloud infrastructure & monitoring system health.

### Release Manager

* Planning release schedules, legal/technical verification, & overseeing application releases.
* Managing release notes & release decision logs.

---

## F. Business Strategy & Product Management

### Product Manager (PM)

* Aligning business vision, roadmaps, & product success metrics.
* Utilizing PM Skill suites (*superPM*) for requirements analysis, growth strategy, & product risk assessment.
* Competitive market analysis & prioritizing business value.

### Product Owner (PO)

* Product Backlog management & drafting detailed User Stories.
* Prioritizing work based on business value & technical readiness.
