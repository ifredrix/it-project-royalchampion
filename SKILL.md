# Skill Directory — Native Desktop Edition (v1.0, 2026-09-07)

A directory of 17 roles across 6 categories. **Do not read all files at once.**
Read ONLY the reference file relevant to the user's request.

## Role Overview (summary — do not open files unless details are requested)

**A. Technical:** Software Architect, Lead Developer, Desktop Application Developer, System & Integration Developer
**B. Management:** Project Manager, Scrum Master
**C. Design:** UX Designer, UI Designer, UX Researcher
**D. Testing:** QA Manual, QA Automation, Security Tester
**E. Infrastructure:** DevOps, SysAdmin, Release Manager
**F. Strategy:** Product Manager, Product Owner

## Usage Rules

1. If the user names one role -> open that role's category file, and only that role's section.
2. If the user names a specific task (e.g., "code signing") -> answer directly from the relevant file without reading other categories.
3. If the user asks for "all roles" -> summarize from the overview table above; do not open reference files unless the user asks for details on a specific role.
4. Small teams (5–7 people): roles can be combined (PM + Scrum Master, UX + UI, DevOps + SysAdmin).
5. Electron/Tauri hybrid -> still usable with minor adjustments.
